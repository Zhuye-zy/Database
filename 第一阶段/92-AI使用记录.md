## 3. 关键规范依据（AI 未生成、来自公开标准）

- INID 码：WIPO **ST.9**（2024-10，p.3.9.4–3.9.7）；
- 国家码：WIPO **ST.3**（2026-08）；文献种类码：WIPO **ST.16**（2016-10 文本）；
- XML 标准：WIPO **ST.36** v1.2、**ST.96** v10.0；
- USPTO 全文 XML：样例 DTD `us-patent-application-v46-2022-02-17.dtd`、`us-patent-grant-v47-2022-02-17.dtd`（第三方公开镜像）；
- EPO DOCDB/PATSTAT：表结构来自 GitHub 公开镜像 `daniel-hain/PATSTAT-PostgreSQL`（Autumn 2018），标注为第三方镜像。

## 4. AI 出过的问题（如实披露，供报告讨论 AI 的能与不能）

1. **3NF 疏漏**：AI 初稿把分类号分量放在关联表 `patent_classification`、并把 `earliest_filing_date` 放在 `patent`；人工按 3NF 复查后发现传递依赖，改用独立 `classification` 表 + 视图派生。
2. **生成脚本小错误**：数据字典脚本中出现未定义的 `NULL` 标记（Python `NameError`），人工运行报错后修正为 `''`。
3. **URL 猜测失败**：AI 推测的 WIPO ST.36 附录 DTD 路径 404，人工排查后确认官网该路径不存在，改为以真实 USPTO 样例 DTD 为准并标注“样例未见”。
4. **样例代表性误判风险**：AI 初期按样例计数（每篇 1 个发明人）可能低估多值基数；人工抽查 208 篇样例的 kind 分布后修正表述（样例以外观设计为主）。
5. **DOCDB 权威性边界**：AI 无法访问 EPO 官方手册，镜像字段名可能与最新版有差异；已列入待人工核对。
