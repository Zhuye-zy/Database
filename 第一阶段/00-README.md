## 3. B 角色快速交接

1. 以 `02-数据字典.csv` 为唯一机器可读基线，用 `03` §3.2 预览表与 `04` 概念图做人工交叉检查。
2. 建表顺序：维表 → `patent` → `publication` → 文献弱实体 → `person` 与 ISA 子类 → 角色/分类/引用 → 族及三个族子表 → 优先权/事件/增强表。
3. 必做复合外键：`publication(publn_auth,publn_kind)`、`patent_classification(scheme_code,symbol)`、`legal_status_event(event_auth,event_code)`。
4. 弱实体用代理 PK + “属主键+部分键” UNIQUE，并对属主删除使用 `ON DELETE CASCADE`。
5. `natural_person`/`organization` 先有 `person` 再插入；`person_type` 与子类存在性用触发器或延迟约束保持一致。
6. `patent_citation.citing_publication_id` 必填；被引文献可在库外，因此解析外键可空但外部号码不可一并丢失。
7. 日期导入必须保留 `*_raw`；`YYYYMM00` 不伪造日，`9999-12-31` 哨兵转 NULL。
8. 尚需选型的项目见 `91`；每项都给出可直接执行的建议默认值。
