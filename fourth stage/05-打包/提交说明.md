## 3. 判据与验收方式（对应报告 4.5 / 5.6 节）

- 全部测试在**一次性容器**里从空库开始执行：`third stage/06-运行管理/verify_fresh.py`。
- 5 类测试脚本共 **151 条用例**，结果文件为 `third stage/07-验收结果/*_result.json`；FAIL / SKIP 一律视为未通过。
- 结束后对 **46 张表**逐表比对内容，再用 `pg_dump` 备份到另一个库恢复并再次比对，两次一致才判定通过。
- 报告中所有数字由 `build_report.py` 从 `逐表行数.json`、`*_result.json`、`analysis_results.json` 注入；PPT 数字复用同一套 `build_ctx()`，避免报告与 PPT 口径漂移。

## 4. 一键复现（仓库根目录执行）

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r 'third stage/01-前端应用/requirements.txt'
bash run.sh                                                    # 建库 + 导入 + 测试 + 前端
.venv/bin/python 'third stage/06-运行管理/verify_fresh.py'      # 全新容器复现 + dump 与恢复比对
.venv/bin/python 'fourth stage/03-分析挖掘/run_analysis.py'     # 21 条分析 SQL + 6 张统计图
.venv/bin/python 'fourth stage/04-流程图与框图/gen_diagrams.py'
.venv/bin/python 'fourth stage/01-设计文档/make_figures.py'     # 生成 21 张报告/PPT 用图
.venv/bin/python 'fourth stage/01-设计文档/build_report.py'     # 报告 docx + 自检
.venv/bin/python 'fourth stage/02-汇报PPT/build_ppt.py'        # 汇报 PPTX + 讲稿 + 自检
.venv/bin/python 'fourth stage/05-打包/package_submission.py'   # 提交包 + 清单
```
