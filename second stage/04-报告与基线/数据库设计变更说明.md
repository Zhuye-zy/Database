# B 阶段设计变更记录

依据：本目录“设计基线”中 A 的 43 表、345 字段字典和正式交接说明。A 原文件不改动，本文件记录 B 的物理实现差异。

| 对象 | 优化前 | 审核后 | 原因 |
|---|---|---|---|
| country_office 四个成员/组织/停用标志 | 必填，导入统一 N | 可空，未查证为 NULL | 样例没有提供信息，N 会制造错误事实 |
| patent.appln_filing_date | NOT NULL | 可空，保留 raw | YYYYMM00 和哨兵不能伪造完整日期 |
| ipc_techn_field.ipc_maingroup_symbol | VARCHAR(8) | VARCHAR(30) | H04L12/00 已有 9 字符 |
| person ISA 延迟触发器 | UPDATE 仅查新键 | 同时核验旧键和新键 | 防止移动子类主键后遗留无子类 person |
| claim / claim_dependency / publication | 缺少部分值域检查 | 正数编号、自引用禁止、非负计数 | 约束异常输入 |
| 表与字段数量 | 43 / 345 | 43 / 345 | 未增删业务表或字段 |

执行顺序：先 `01-create-schema.sql`，再 `02-audit-migration.sql`。现有数据库只执行第二个文件，由 `update_reviewed.sh` 统一备份及更新。

第二个 SQL 可重复运行。优化前版本与数据库备份在“08-历史备份”；旧版报告不代表本次验收结论。

数据语义修正还包括：剔除虚构族号、分离 DOCDB 文献摘要与族摘要、保留 NPL 全文、修复附图文件名、补齐传统 IPC / 优先权 / 指定国。空表不构成伪造记录的理由。

补充：保留DOCDB及法律样例明确提供的申请种类A；未知仍为NA。
