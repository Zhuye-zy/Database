# 官方来源材料

- **01-四类基础样例**：从 A 已归档的官网样例复制，独立可复现；包含 US 申请 4 篇、US 授权 8 篇、EP 全文 4 篇、DOCDB Amend 2 篇，共 17 个 XML 文件、18 篇逻辑文献。原目录中的非 XML 附件仍保留。
- **02-IPDPS补充样例/01-压缩原包**：新版官网获取的原ZIP按五类分目录；两个US解包RAR已验证与ZIP载荷完全一致后移除，避免重复打包。
- **02-IPDPS补充样例/02-DOCDB原文**：CreateDelete原XML；Amend只保留基础样例中的一份及原ZIP，删除重复解包副本。CreateDelete的5条CV是撤回通知，按EPO规则登记审计，不伪造申请。
- **02-IPDPS补充样例/03-法律状态原文**：1 篇法律状态 XML。包含 10 个事件。包装根缺闭合标签，由解析器仅在内存补齐；原文件保持原样。
- **02-IPDPS补充样例/04-法律状态原始附件**：法律事件代码包、统计表、索引、DTD/XSD、内层压缩包等。它们是官方交付附件，未把 XLSX/RAR 伪称为已导入数据库。
- **03-数据手册**：四类目标数据手册及 EP 法律状态手册。

来源入口： https://ipdps.cnipa.gov.cn/#/MyHome 。本轮保留归档，并实际联网校验五类样例；没有下载全量数据。
