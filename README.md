# 专利数据关系数据库设计

天津大学《数据库实践》题目 5 第一阶段交付仓库。项目面向四类专利数据：美国申请公布全文、美国授权公告全文、EP 全文和 EP DOCDB 摘要，完成从 XML 数据调研到本地关系数据库概念设计的交接。

## 当前状态

- 第一阶段 A 角色（数据调研与概念设计）已完成并通过自检；
- 最终设计口径：43 张表（核心 38 + 增强 5）、345 个字段、45 个联系集；
- 概念 E/R 图严格区分实体集、联系集、弱实体集、ISA、映射基数和参与约束；
- 四类官网样例均已解析，字段可追溯到手册、INID 码或真实 XML 路径；
- 下一步由 B 角色完成关系表确认、建表 SQL 和批量解析/导入程序。
